# RepoPilot v0.2 Improvement Plan

## Summary
Upgrade RepoPilot from the local-state MVP to v0.2 focused on sync visibility, dashboard filtering, bulk progress, a repository detail drawer, recent SQLite-backed activity, command palette, and more polished app states.

Confirmed choices:
- Store recent action history in SQLite.
- Replace the existing repository detail page with a `Sheet` drawer.
- No AI features, Git diff viewer, commit panel, branch graph, OAuth, PR integration, or cloud sync.

## Key Changes
- Extend Rust and TypeScript repository models with ahead/behind sync status and skipped action state.
- Add SQLite-backed recent activity commands while keeping workspace/repository state in Zustand.
- Add dashboard status filters, result count, sync column, bulk progress card, recent activity panel, and dropdown row actions.
- Replace detail navigation with a Sheet drawer.
- Add a Command palette opened by Cmd/Ctrl+K.

## Test Plan
- Rust tests for sync parsing, no-upstream refresh behavior, and SQLite activity recording/query/clear.
- Frontend tests for status priority, search/filtering, summary counts, bulk progress, activity formatting, and command palette visibility.
- Full verification: `pnpm test`, `pnpm lint`, `pnpm build`, `cargo test`, `pnpm tauri build`, and browser workflow screenshots.
